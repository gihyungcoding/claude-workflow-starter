#### 상태별로 무엇이 보이나

<!--
  ★ 이 부분이 시안을 대신한다. 각 상태마다 화면에 무엇이 있는지 적는다.
    "예쁘게"가 아니라 "무엇이 보이는가"를 쓴다 — 생김새는 UI 라이브러리가 정한다.

  빠뜨리기 쉬운 상태: 빈 목록 · 로딩 · 오류 · 권한 없음 · 아주 긴 텍스트 · 항목이 아주 많을 때
-->

- **기본** — 할 일이 카드 목록으로. 각 카드에 제목 · 마감일 · 완료 체크박스
- **로딩** — 카드 자리에 스켈레톤 3개
- **빈 목록** — "아직 할 일이 없습니다" + `[새로 만들기]` 버튼
- **오류** — "목록을 불러오지 못했습니다" + `[다시 시도]` 버튼

**이 상태 목록이 그대로 §4 완료 조건이 된다.** 적어놓고 완료 조건에 없으면 검증되지 않는다.

**이 화면이 필요로 하는 데이터가 §2 API 명세가 된다.** 화면을 먼저 적고 API 를 도출하면
"만들고 보니 이 필드가 없다"를 피할 수 있다.
